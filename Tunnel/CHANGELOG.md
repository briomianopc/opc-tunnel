# 更新日志

## v1.1.0 - 2025-12-15

### 新增功能
- ✅ **配置持久化**: 自动保存和加载配置到 `%AppData%/OpcTunnelGUI/config.json`
- ✅ **系统托盘**: 支持最小化到系统托盘
- ✅ **托盘菜单**: 右键托盘图标可快速访问功能
  - 显示主界面
  - 开启/关闭系统代理
  - 开启/关闭 TUN 模式
  - 退出程序
- ✅ **优选 IP 支持**: 支持 CDN 优选 IP 和 CNAME 域名
- ✅ **自动化构建**: 提供完整的自动化构建脚本

### 修复问题
- ✅ **中文编码**: 修复日志中文乱码问题（使用 GB2312 编码）
- ✅ **窗口关闭**: 点击 X 按钮最小化到托盘而不是退出
- ✅ **配置保存**: 连接时自动保存配置

### 改进
- 📝 更新界面提示文本，明确优选 IP 功能
- 📝 完善文档说明
- 🔧 优化构建流程
