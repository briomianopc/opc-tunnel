# OPC Tunnel GUI - 功能详解

## 界面布局

### 1. 顶部状态栏
- **标题**: OPC Tunnel
- **副标题**: 基于 ECH 的网络隧道客户端
- **状态指示器**: 实时显示连接状态
  - 灰色: 未连接
  - 橙色: 正在连接
  - 绿色: 已连接
  - 红色: 连接错误

### 2. 配置区域

#### 基本配置
- **服务器地址**: 
  - WebSocket 格式: `your-worker.workers.dev:443`
  - gRPC 格式: `grpc://your-server:50051`
  - 支持自定义端口

- **身份令牌**: 
  - WebSocket 模式: 使用 UUID
  - gRPC 模式: 使用 UUID 作为 metadata

- **监听地址**: 
  - 本地代理服务器地址
  - 默认: `127.0.0.1:30000`
  - 支持 SOCKS5 和 HTTP 代理

- **传输模式**:
  - WebSocket (ws): 基于 WebSocket 的隧道
  - gRPC: 基于 gRPC 双向流的隧道

- **并发连接数**:
  - 范围: 1-10
  - 默认: 1
  - 多连接可提高并发性能

#### 高级设置

- **服务器 IP**:
  - 可选配置
  - 直接指定服务器 IP 地址
  - 绕过 DNS 解析，提高连接速度

- **DNS 服务器**:
  - DoH (DNS over HTTPS) 服务器
  - 默认: `dns.alidns.com/dns-query`
  - 用于查询 ECH 配置

- **ECH 域名**:
  - 用于查询 ECH 配置的域名
  - 默认: `cloudflare-ech.com`

- **禁用 ECH (Fallback 模式)**:
  - 关闭 ECH 加密
  - 使用普通 TLS 1.3 连接
  - 适用于不支持 ECH 的环境

- **启用 TUN 模式**:
  - 全局透明代理
  - 需要管理员权限
  - 捕获所有网络流量
  - 配置项:
    - TUN IP: `10.0.85.2`
    - TUN 网关: `10.0.85.1`
    - TUN 子网掩码: `255.255.255.0`
    - TUN DNS: `1.1.1.1`

- **自动设置系统代理**:
  - 自动配置 Windows 系统代理
  - 程序退出时自动恢复
  - 仅在非 TUN 模式下有效

### 3. 日志区域

- **实时日志显示**:
  - 显示隧道程序的所有输出
  - 时间戳格式: `[HH:mm:ss]`
  - 自动滚动到最新日志

- **日志类型**:
  - `[输出]`: 正常输出信息
  - `[错误]`: 错误信息
  - `[启动]`: 启动相关信息
  - `[ECH]`: ECH 配置信息
  - `[传输层]`: 传输层信息

- **日志管理**:
  - 最多保留 500 条日志
  - 超出自动删除最旧的日志
  - 支持清除所有日志

### 4. 控制按钮

- **连接按钮**:
  - 启动隧道连接
  - 连接后自动禁用
  - 绿色主题

- **断开按钮**:
  - 停止隧道连接
  - 未连接时禁用
  - 红色主题

## 工作流程

### 连接流程

1. **配置验证**:
   - 检查服务器地址是否为空
   - 检查身份令牌是否为空
   - 验证监听地址格式

2. **启动隧道**:
   - 构建命令行参数
   - 启动 ech-core.exe 进程
   - 重定向标准输出和错误输出

3. **状态监控**:
   - 实时读取进程输出
   - 解析日志判断连接状态
   - 更新界面状态指示器

4. **连接成功**:
   - 状态变为"已连接"（绿色）
   - 记录连接时间
   - 启用断开按钮

### 断开流程

1. **发送停止信号**:
   - 向进程发送停止命令
   - 等待进程优雅退出

2. **超时处理**:
   - 3 秒超时
   - 超时后强制终止进程

3. **清理资源**:
   - 释放进程资源
   - 更新界面状态
   - 恢复系统代理设置（如果启用）

## 技术实现

### MVVM 架构

```
View (MainWindow.axaml)
  ↓ 数据绑定
ViewModel (MainWindowViewModel.cs)
  ↓ 调用服务
Service (TunnelService.cs)
  ↓ 管理进程
ech-core.exe
```

### 数据绑定

- **单向绑定**: View → ViewModel
  - 用户输入配置
  - 按钮点击命令

- **双向绑定**: View ↔ ViewModel
  - 配置参数
  - 复选框状态

- **通知机制**: ViewModel → View
  - 状态变化
  - 日志更新
  - 连接状态

### 进程管理

- **进程启动**:
  - 使用 `Process.Start()`
  - 重定向标准输入/输出/错误
  - 设置工作目录

- **输出捕获**:
  - 异步读取标准输出
  - 异步读取错误输出
  - UTF-8 编码支持

- **进程监控**:
  - 监听进程退出事件
  - 自动更新连接状态
  - 异常处理

### 状态管理

```csharp
public enum ConnectionState
{
    Disconnected,  // 未连接
    Connecting,    // 正在连接
    Connected,     // 已连接
    Error          // 错误
}
```

## 性能优化

1. **日志限制**: 最多 500 条，防止内存溢出
2. **异步操作**: 所有 I/O 操作使用异步
3. **资源释放**: 及时释放进程和流资源
4. **UI 线程**: 避免阻塞 UI 线程

## 安全考虑

1. **进程隔离**: GUI 和核心程序分离
2. **权限检查**: TUN 模式需要管理员权限
3. **输入验证**: 验证所有用户输入
4. **错误处理**: 捕获并显示所有错误

## 故障排查

### 常见问题

1. **找不到 ech-core.exe**:
   - 检查文件是否存在
   - 确保构建时复制了文件
   - 查看日志中的路径信息

2. **连接失败**:
   - 检查服务器地址是否正确
   - 验证身份令牌是否有效
   - 查看日志中的错误信息

3. **TUN 模式启动失败**:
   - 确保以管理员身份运行
   - 检查 wintun.dll 是否存在
   - 查看系统是否支持 TUN

4. **日志不显示**:
   - 检查进程是否正常启动
   - 验证输出重定向是否正常
   - 查看是否有编码问题
